# Photo Proof V1 - Setup Guide

## 🚀 Quick Start

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

The app will run on **http://localhost:3001** (different port from main app to avoid conflicts).

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## ⚙️ Configuration

### Port Configuration
The app runs on port **3001** by default (configured in `vite.config.ts`).

To change the port, edit `vite.config.ts`:
```typescript
server: {
  port: 3001, // Change this to your desired port
  host: '0.0.0.0',
  open: true,
}
```

### API Keys (Optional)
If you need to use Google Gemini API, create a `.env` file:
```bash
GEMINI_API_KEY=your_api_key_here
```

## 🔄 Running Both Apps Simultaneously

You can run both the main Photo Proof app and this V1 version at the same time:

1. **Main App** (photo_proof folder):
   ```bash
   cd ../photo_proof
   npm run dev
   ```
   Runs on: http://localhost:5173

2. **V1 App** (Photo_Proof_v1 folder):
   ```bash
   cd Photo_Proof_v1  # or stay in this directory
   npm run dev
   ```
   Runs on: http://localhost:3001

## 🐛 Troubleshooting

### Port Already in Use
If port 3001 is already in use, either:
1. Stop the process using that port
2. Change the port in `vite.config.ts`

### Dependencies Issues
```bash
rm -rf node_modules package-lock.json
npm install
```

### Build Errors
Make sure you have Node.js 16+ installed:
```bash
node --version
```
